Dados e backup

Exporte uma cópia dos alunos, fichas e registros de conclusão em arquivo JSON. Guarde o arquivo em local seguro.

A importação substitui os dados existentes neste navegador.

Esta versão é um protótipo funcional local. Para disponibilizar aos alunos por um link com contas individuais, será necessário publicar o site e adicionar autenticação e banco de dados online.
